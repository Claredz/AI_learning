# AI Learning Journal

这是一个用来记录我学习 AI 基础过程的仓库。

我会在这里保存实验代码、学习笔记、实验观察和接下来的尝试方向。

我当前正在做的主线是：
- 用 `NumPy` 手写最小 MLP
- 一边写代码，一边理解前向传播、反向传播和训练过程
- 把实验结果和自己的理解一起记录下来

## 我在这里记录什么

- `experiments/`：动手验证想法的地方
- `notes/`：学习中的理解、困惑、推导和复盘
- `reports/`：每次实验之后留下的观察和总结
- `data/`：实验中使用的原始数据
- `figures/`：后续保存训练曲线或可视化结果
